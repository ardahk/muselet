# Cloud builder: "advisor mode" demo — on-device meeting prep (Muselet)

Repo `ardahk/muselet`. Read `AGENTS.md` first. Muselet is a fully on-device macOS voice agent (Apple Silicon,
MLX). Inspiration: Savvy Wealth's "Savvy Intelligence" (savvywealth.com/savvy-intelligence): an AI workspace for
financial advisors whose Financial Planning Agent assembles a household's full picture before a client meeting,
flags opportunities (Roth conversion window, tax-loss harvesting, cash drag), and produces a client-ready summary.
Our twist for the demo: the advisor says "prep me for my meeting with the Hendersons" with **Wi-Fi off**; Muselet
reads Calendar, the client folder in Finder, the portfolio in Numbers and last meeting's notes, then writes a brief
into Notes and highlights the opportunities in the sheet. Client data never leaves the Mac. Every number comes from
deterministic code with the evidence attached; the on-device LLM only phrases sentences.

Work on branch `cloud/advisor` (from `main`), commit often, push, open one PR to `main` when done. Do not modify
`ml/src/brain/{decision,orchestrator,server,cli,catalog,planner}.py`, `ml/src/brain/finance/`, `app/`, `skills/`
or `evals/route_v1.jsonl`; other agents own them. You have no API keys and need none.

## 1. Fixtures `evals/fixtures/advisor/henderson/` (generated by `generate.py`, deterministic, truth by code)
Household: Mark (62) and Elena (60) Henderson, married filing jointly, California, as-of date 2026-10-23, all
prices fixed in the files (the demo is offline). Files:
- `portfolio.xlsx` (Numbers opens it) and `portfolio.csv`: sheet `Holdings` with Account, Ticker, Name, Asset class
  (US equity / Intl equity / Bonds / Cash), Lot date, Shares, Cost basis, Price, Market value, Unrealized G/L.
  Accounts: Joint taxable brokerage, Mark Traditional IRA, Elena Roth IRA, Savings. 12-18 positions, several
  multi-lot positions in taxable. Total ~$1.4-1.8M.
- `targets.json`: target allocation 60% equity (40 US / 20 intl), 35% bonds, 5% cash; rebalance band ±5 percentage
  points per asset class.
- `activity_last_60d.csv`: buys/sells across all accounts.
- `profile.json`: filing status, ages, estimated 2026 taxable income before any conversion ($150,000), monthly
  expenses ($8,000), goals.
- `last_meeting_notes.txt` (from 3 months ago): mentions a lake house down payment of $120,000 next spring and
  interest in charitable giving.
- `annual_review.ics`: "Henderson annual review", 2026-10-26 10:00-11:00 local.
Planted, exact facts (assert them in `generate.py`; recompute every truth value from the files):
- Current allocation drifted to roughly 68/27/5 → equity over the band, bonds under it; rebalance trades restore
  target using taxable-account-aware rules (prefer trades inside IRAs to avoid realizing gains; document the rule).
- Exactly 3 taxable lots with unrealized loss >= $1,000. One of them is wash-sale blocked: the same ticker was
  bought in Mark's IRA 12 days before the as-of date. Replacement pairs from a fixed table (VTI→ITOT, VXUS→IXUS,
  BND→AGG, etc.).
- Savings far above 6 months of expenses → cash excess = savings − 6 × monthly expenses, minus the lake-house
  reserve from the notes (document the rule).
- Roth conversion room = top of the 22% bracket for MFJ 2026 minus estimated taxable income. Use the official IRS
  2026 figures (IRS Rev. Proc. for tax year 2026): fetch them, cite the source URL and the exact numbers in
  `README.md` and in code constants. If you cannot verify a number from an official source, stop and leave
  `TODO(lead)` instead of guessing. Same rule for any IRMAA threshold you mention; omit IRMAA if unverifiable.
- Donation candidates: the 2 taxable lots with the highest unrealized gain percentage held > 1 year (gifting
  appreciated stock to a donor-advised fund avoids the gain).
- `truth.json`: allocation (current, target, drift), rebalance trades, TLH list (lot, loss, status
  ok|wash_sale_blocked, replacement), harvestable loss total (excluding the blocked lot), cash excess, Roth room,
  donation candidates.

## 2. Deterministic engine `ml/src/brain/advisor/` (stdlib only, `Decimal` money)
- `load_household(dir)`, `allocation(h)`, `rebalance_trades(h, band)`, `tlh_candidates(h, min_loss, wash_days=30)`,
  `cash_excess(h, months)`, `roth_room(h, year)`, `donation_candidates(h, n)`, each returning values plus an
  `evidence` list (rows/lots and the rule that fired).
- `prep(h) -> dict` (everything above) and `brief_markdown(prep, phrasing=None) -> str`: a one-page brief with
  sections Snapshot, Opportunities (ranked by $ impact), Talking points (lake house, charitable giving), Proposed
  actions. Numbers are filled from `prep` only; `phrasing` is an optional dict of short sentences the LLM may
  supply, never numbers.
- AppleScript generators (strings only; golden tests): Numbers (`tell application id "com.apple.Numbers"`):
  highlight TLH lots (green), the blocked lot (amber), add a `Review` sheet with the allocation table and the
  trades in one call each. Notes: create a note in folder "Clients" titled "Henderson — annual review prep" with
  the brief as HTML. Escape everything.
- CLI: `python -m brain.advisor prep --household evals/fixtures/advisor/henderson` → JSON + markdown. Tests in
  `ml/tests/test_advisor.py` assert the CLI output equals `truth.json` to the cent. Run with a plain venv +
  pytest (`PYTHONPATH=ml/src python -m pytest ml/tests/test_advisor.py`); `uv sync` may fail on Linux (mlx).
